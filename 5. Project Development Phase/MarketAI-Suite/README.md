# MarketAI Suite 🤖
### AI-Powered Sales & Marketing Intelligence Platform

MarketAI Suite is a Generative AI-powered sales and marketing intelligence platform built with **Python, Flask, SQLite, and Groq (LLaMA 3.3 70B)**.

---

## 🌟 Key Features

1. **AI Marketing Campaign Generator**: Generates end-to-end marketing campaigns including positioning statements, brand slogans, promotional content, social media captions, email sequences, timelines, and KPIs.
2. **AI Sales Pitch Generator**: Generates customized, consultative sales pitches including executive summaries, 30-second elevator pitches, objection handling, discovery questions, and follow-up email templates.
3. **Lead Scoring Engine**: Evaluates manual leads and CSV uploads (hundreds of leads) combining deterministic business rules with AI reasoning to produce 0-100 scores, priorities (High/Medium/Low), conversion estimates, and next actions.
4. **Audience Segmentation Assistant**: Segments target markets into distinct customer personas with buying behavior, needs, pain points, channel preferences, and recommended offers.
5. **Marketing Strategy Generator**: Constructs 12-month go-to-market strategies complete with market analysis, channel budget allocations, implementation roadmaps, and risk mitigations.
6. **AI Recommended Actions**: Generates context-aware "Next Best Action" recommendations prioritised by business impact.
7. **Persistent Session History**: Every AI generation is saved to SQLite. Re-opening a previously generated result loads directly from the database with **zero API calls** to Groq.
8. **Dashboard & Exports**: Provides real-time metrics, charts, and CSV report export functionality.

---

## 🏗️ Technology Stack

- **Backend**: Python 3.11+, Flask, Flask REST API, SQLite, Pandas, python-dotenv
- **AI Engine**: Groq SDK (`groq`), LLaMA 3.3 70B (`llama-3.3-70b-versatile`)
- **Frontend**: HTML5, Vanilla CSS3 (Custom Design Tokens), Vanilla JavaScript (Fetch API, zero heavy frameworks)

## 🚀 Quick Start Guide

### Prerequisites
- Python 3.11 or higher
- A Groq API Key (Get a free key at [Groq Console](https://console.groq.com/))

### 1. Installation

```bash
# Clone or navigate to the project directory
cd MarketAI-Suite

# Create a virtual environment
python -m venv venv

# Activate virtual environment
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# Linux / macOS:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### 2. Environment Setup

Create a `.env` file in the project root (copied from `.env.example`):

```ini
GROQ_API_KEY=gsk_your_actual_groq_api_key_here
GROQ_MODEL=llama-3.3-70b-versatile
FLASK_ENV=development
FLASK_DEBUG=True
SECRET_KEY=dev_secret_key_change_in_prod
DATABASE_PATH=database/marketai.db
MAX_CONTENT_LENGTH=10485760
```

### 3. Run the Application

```bash
python app.py
```

The application will start at `http://127.0.0.1:5000/`.

## 🏛️ Architecture & Prompt Strategy

### Architecture
`Browser (Fetch API) → Flask REST API → MarketAI Intelligence Engine → Groq API (LLaMA 3.3 70B)`
- **Centralised AI Service**: `services/groq_service.py` handles all Groq SDK calls, timeout retries, error mapping, and JSON response parsing.
- **Zero API Key Exposure**: The Groq API key is stored strictly on the backend in `.env` and is **never** sent to the client.
- **Persistent History**: All generated results are stored in SQLite (`database/marketai.db`). Opening history loads directly from database records without triggering new AI requests.

### Lead Scoring Logic
Combines deterministic scoring rules (demo requests, engagement scores, intent signals, decision-maker job titles) capped at 60 points with AI contextual analysis (up to 40 points) to compute a final 0-100 score and priority categorisation.
